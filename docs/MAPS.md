# 地图设计（10 张，传奇结构）

## 设计基准

- 1 格 = 1 米。野外 100–160 格见方，地下城每层 70–90 格，BOSS 房 50–60 格。
- 每张图 3–6 个子区域，至少 1 个安全点、1 个传送点、1 个隐藏入口。
- 主线路线 4–8 分钟走完，全图探索 15–25 分钟。
- 地下城必须多层，层与层之间有回城点、单向门或钥匙门槛。
- 4–5 人联机：可分队走不同路线，机关要配合，BOSS 有点名和分摊。

## 地面区域复用与主题（v1）

- 10 张概念图是等距布局图，只用于看结构、取配色和挑地面样本；运行时不直接拿整张图做平铺。
- 每张图已裁出一块纯地面参考，放在 `assets/concept/maps/ground_regions/`。
- 运行时地面为 512×512 无缝材质，2 米 1 tile；每张图 A 为主地面，B 为路径/次级地面。
- 主题参数统一在 `data/map_themes.json`，由 `MapThemes` autoload 读取，再由 `map_environment.gd` 套到地面、环境光和方向光。
- 可复用角色：
  - `tile_a`：战斗区、BOSS 区、普通野外。
  - `tile_b`：营地、安全区、道路、房间连接处。
  - 同一套材质可通过 UV 缩放复用到大广场、窄路和房间，不额外画图。

## 黄沙岗白盒（当前实现）

- `data/map_layouts.json` 已包含 `MAP_01_ASHEN_YARD` 的 100×100 地面布局。
- `src/gameplay/map_layout.gd` 从该文件生成：
  - 100×100 主地面，A 夯土沙地。
  - 出生营地 / 枯木坡 / 废弃车阵 / 流沙坑四个区域。
  - 营地 → 枯木坡 → 废弃车阵 → 流沙坑 → 回营的环形 B 路面。
  - 边界墙、简单道具和安全区标记。
- `src/gameplay/enemy_spawner.gd` 改成读取同一份布局数据的 `spawns`。
- 当前怪物名和模型仍是占位体；黄沙岗真正的沙鼠 / 瘦狼 / 沙鼠王后续按 ID 替换。
- 流沙坑区域会降低玩家移动速度；出生营地有安全区提示，怪物会推开自己、停止追击。
- 10 张图的布局数据已全部写入 `data/map_layouts.json`，游戏内按数字键 1–0 可切图。

## 1. 黄沙岗（MAP_01_ASHEN_YARD）

- 类型：新手野外，无地下城。
- 尺寸：100×100。
- 子区域：
  - 出生营地（10×10，安全区，铁叔与阿萝）
  - 枯木坡（西南，30×30，沙鼠）
  - 流沙坑（东南，30×30，瘦狼，减速地形）
  - 废弃车阵（北侧，20×20，精英沙鼠王）
- 刷怪：沙鼠 30、瘦狼 24、沙鼠王 1，刷新 3 秒，密度高。
- 机制：无 BOSS；死亡不掉落；20 级后经验衰减。
- 路线：营地 → 枯木坡 → 车阵 → 流沙坑 → 回营。
- 协作：4 人可分两路刷，营地共享仓库。
- 产出：白装、绿装、初级药水、金币。

## 2. 沙地遗迹（MAP_02_RUIN_SANDS）

- 类型：野外 + 三层地下城。
- 尺寸：野外 140×140；地宫每层 80×80；BOSS 房 60×60。
- 野外子区域：遗迹广场、沙海古道、断柱回廊、地下入口（北）、绿洲补给点。
- 地下层：
  - 一层「墓道」：直线主路 + 两条侧廊，野猪与弓手
  - 二层「地宫」：环形房间，自爆虫与牛魔精英
  - 三层「沙虫巢穴」：流沙池 + BOSS 房
- BOSS：沙虫王。钻地突袭、沙暴 AOE、召唤 4 只小沙虫；破韧倒地 3 秒。
- 路线：广场 → 古道 → 回廊 → 地宫一层 → 二层 → 三层 → BOSS。
- 协作：二层需要两人同时踩机关开门；BOSS 沙暴要分散站位。
- 产出：蓝装、紫装、强化石、沙虫皮。

## 3. 幽影森林（MAP_03_SHADOW_FOREST）

- 类型：野外 + 三层地下城（树根迷宫）。
- 尺寸：野外 150×150；迷宫每层 80×80；BOSS 房 55×55。
- 野外子区域：迷雾小径、荧光沼泽、猎人营地（安全）、树妖祭坛、地下树洞。
- 地下层：
  - 一层「根须迷宫」：8 个房间随机连通，需点火把标记
  - 二层「腐化池」：毒雾 + 孢子爆炸
  - 三层「树心」：BOSS 房
- BOSS：千年树妖。根须缠绕、毒藤召唤、全屏孢子；火把范围内免毒。
- 路线：小径 → 沼泽 → 祭坛 → 树洞 → 三层 → BOSS。
- 协作：迷宫需要分头探路并报点；BOSS 战需一人守火把。
- 产出：紫装、解毒药、千年木心。

## 4. 寒霜堡垒（MAP_04_FROST_KEEP）

- 类型：城镇 + 要塞四层。
- 尺寸：外城 120×120；内层 75×75；龙巢 60×60。
- 子区域：关隘、校场（安全）、城墙、兵营、冰窖、龙巢。
- 层数：城墙 → 兵营 → 冰窖 → 龙巢。
- BOSS：冰霜巨龙。冰息扇形、冰锥落点、全场冻结；火盆驱散极寒层数。
- 机制：极寒每层减速 5%，最多 10 层；火盆每秒减 1 层。
- 路线：关隘 → 校场 → 城墙 → 兵营 → 冰窖 → 龙巢。
- 协作：城墙段需双人拉闸；龙巢火盆要轮流守。
- 产出：紫装、橙装碎片、冰抗宝石。

## 5. 熔岩深渊（MAP_05_LAVA_DEPTHS）

- 类型：五层矿洞，无野外。
- 尺寸：每层 80×80；BOSS 房 60×60。
- 层数：
  - 一层「矿口」：安全点 + 商店
  - 二层「熔岩河」：石桥与岩浆
  - 三层「铁索桥」：窄桥 + 火虫
  - 四层「火魔殿」：精英火魔
  - 五层「炎魔巢」：BOSS
- BOSS：炎魔。熔岩喷发、火焰旋风、地裂；击杀火魔留下安全区。
- 机制：岩浆每秒 3% 最大生命；桥面会阶段性断裂。
- 路线：单线向下，四层有回城点。
- 协作：铁索桥需要战士先过拉仇恨，法师远程清火虫。
- 产出：橙装、火抗宝石、炎魔之心。

## 6. 黄泉鬼域（MAP_06_UNDERWORLD）

- 类型：鬼城野外 + 四层地府。
- 尺寸：鬼城 130×130；地府 80×80；阎罗殿 60×60。
- 子区域：鬼门关、黄泉路、奈何桥、鬼市（安全）、阎罗殿入口。
- 层数：黄泉路 → 奈何桥 → 阎罗殿 → 鬼王座。
- BOSS：鬼王。召唤鬼潮、锁链拖拽、全屏恐惧；30% 血进入狂暴。
- 机制：每只存活怪给玩家叠 1 层诅咒，每层受伤 +2%，最多 20 层。
- 路线：鬼门 → 黄泉路 → 鬼市补给 → 奈何桥 → 阎罗殿。
- 协作：奈何桥限时通过，需有人断后；BOSS 恐惧要分散。
- 产出：橙装、转生材料、鬼王令。

## 7. 天空浮岛（MAP_07_SKY_ISLES）

- 类型：浮空群岛 + 三层风眼。
- 尺寸：群岛 160×160；风眼每层 70×70；BOSS 台 55×55。
- 子区域：起飞台（安全）、风带、断桥、雷瀑、风眼入口、雷鹏巢。
- 层数：风眼外层 → 风眼内层 → 雷鹏巢。
- BOSS：雷鹏。俯冲、落雷、掀风推人下平台。
- 机制：强风区持续推移；掉下平台损失 20% 生命并回起点。
- 路线：起飞台 → 风带 → 断桥 → 雷瀑 → 风眼 → BOSS。
- 协作：断桥需要两人同时踩风阀；BOSS 掀风时全队贴边。
- 产出：橙装、稀有宝石、雷羽。

## 8. 海底龙宫（MAP_08_DRAGON_PALACE）

- 类型：水下宫殿 + 四层龙宫。
- 尺寸：外海 140×140；龙宫 80×80；龙王殿 60×60。
- 子区域：珊瑚林、沉船、宫门、珍珠殿（安全）、龙柱阵、龙王殿。
- 层数：长廊 → 珍珠殿 → 龙柱阵 → 龙王殿。
- BOSS：龙王。水龙卷、护盾反伤、全场水压；破盾后才能满伤。
- 机制：水压每 10 秒一次，需进气泡躲避。
- 路线：珊瑚林 → 沉船 → 宫门 → 长廊 → 珍珠殿 → 龙柱阵 → 龙王殿。
- 协作：龙柱阵需三人同时点亮；护盾阶段要停手等破盾。
- 产出：红装、毕业武器材料、龙鳞。

## 9. 魔域·血月（MAP_09_BLOOD_MOON）

- 类型：终局野外 + 五层魔殿。
- 尺寸：野外 160×160；魔殿每层 90×90；魔尊殿 60×60。
- 子区域：血月荒原、魔军营地、血池、魔殿入口、祭坛（安全）。
- 层数：魔殿一层到五层，每层一个魔将。
- BOSS：魔尊，三阶段；30% 血狂暴，召分身。
- 机制：血月每 30 秒刷一波精英；击杀叠嗜血，伤害 +5%，最多 10 层。
- 路线：荒原 → 营地 → 血池 → 魔殿五层 → 魔尊殿。
- 协作：五层魔将可分队同时打；魔尊分身需要集火标记。
- 产出：红装、神话碎片、转生材料。

## 10. 擂台·天下第一（MAP_10_ARENA）

- 类型：独立竞技场，50×50。
- 规则：10 波连战，每波 30 秒；每 5 波一个 BOSS；波次无限循环。
- 难度：青铜（20 级）、白银（40 级）、黄金（60 级）。
- 限制：不能吃药，只能靠吸血和击杀回血；死亡直接结算，不扣金币。
- 协作：支持 1–5 人组队，人数越多波次强度越高。
- 奖励：竞技币，换称号、光环、外观；记录本地最高波次。

## 4–5 人联机深度

- 队伍人数缩放：怪物血量 ×(1 + 0.6×(n−1))，伤害 ×(1 + 0.25×(n−1))，精英数量 +1。
- 职业互补：战士拉仇恨破防，法师 AOE 控场，道士治疗、施毒、召唤。
- 复活：倒地 30 秒，道士可复活；全灭回最近安全点。
- 掉落：独立掉落 + 分配模式（自由 / 轮流 / 队长）。
- 机关：双人踩板、三色灯、限时门，逼队伍分工。
- BOSS：点名、分摊、打断、站位，四人以上才需要完整处理。

## 资产替换规则

- 每张图至少：地砖 A/B、2 个场景道具、1 个地标、1 张加载图。
- 模型命名用 `ENV_<地图>_<类型>`，替换只换文件不改代码。
- 所有地图共用一套相机、光照和特效预算。
