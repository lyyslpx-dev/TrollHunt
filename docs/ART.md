# 美术规范

## 风格关键词
Q 版、三头身、大头、粗描边、高饱和、厚涂、金框深色 UI。

## 目标品质基准

- 参考“胖哥”设定集：Q 版轮廓 + 写实皮肤、布料和柔和棚拍光。
- 最终战斗角色 20–30k 三角面，选人特写 80–150k；2K PBR 图集，脸部单独 1K。
- 材质采用卡通与 PBR 混合：三阶 ramp、柔和高光、边缘光和假 SSS，不做纯平涂。
- 毛孔、肚子体积、布料褶皱主要靠高模烘焙的法线、AO 和曲率贴图表现，实时模型不加细分。
- 四人同屏时玩家 LOD 降到 8–12k，小怪 2–4k，BOSS 15–25k。

## 角色
- 比例：2.5–3 头身，头约占身高 40%
- 三名可玩职业均为男性，服装与脸型不做女性版本
- 面数：主角 20–30k（战斗）/ 80–150k（选人特写），小怪 4–6k，精英 8–12k，BOSS 20–35k
- 贴图：角色 2048，脸部单独 1024
- 卡通着色：三阶 ramp + 柔和高光 + 边缘光 + 假 SSS
- 描边：inverted hull，屏幕空间约 2px，中高档开启

## 场景
- 地砖 512 可平铺，建筑与遗迹低模块化
- 单张图复用 3–5 个模块
- 单屏可见三角面 70–150k
- 地面按 2 米 1 tile 使用；主地面和路径各一套，靠 UV 缩放复用
- 等距布局图只做结构、配色和取样参考，不直接当平铺贴图

## 特效清单（按优先级）
1. 光柱：加色面片 + UV 滚动
2. 冰锥 / 地刺：低模 + 发光材质
3. 剑气：带状网格 + 拖尾
4. 爆裂：粒子 + 闪白 + 震屏
5. 闪电链：折线 + 加色
6. 地面裂纹：贴花
7. 拾取光柱：品质色
8. 受击闪白：材质参数
9. 伤害飘字：2D，暴击放大

## Overdraw 控制
- 单个技能同时最多 3 层全屏加色
- iPhone 12 特效强度 70% 时粒子数 ≤ 300
- 大招允许一次全屏闪白，持续 ≤ 0.12 秒

## UI
- 深色木纹或石纹底 + 金色描边框
- 品质色：白 `#FFFFFF`、绿 `#4CD964`、蓝 `#3B9EFF`、紫 `#B45CFF`、橙 `#FF9F0A`、红 `#FF3B30`、神话 `#FFD700` 渐变
- 按钮最小 44pt，主要按钮 64pt

## 图标
- 装备图标 256×256，UI 图标 128×128
- 先用 imagegen 出草图，再统一描边和色调
- 同一部位共用底板，只换主体

## Blender 流程
- 1 米单位，导出 glTF，朝向 -Z
- 角色 A-pose，骨骼 ≤ 50
- 表情用贴图切换，不做面部骨骼
