## 已知问题
- 桌面端机型识别走 GPU 兜底，显示中档属正常
- 怪物重叠已用分离力缓解，密集时仍可能轻微挤压
- 技能没有前摇动作，伤害即时结算
- 怪物名称与血条在密集时会重叠
- 设置页的调试截图参数：`-- --shot` 与 `-- --shot-settings`，输出到 `user://shot_main.png`
- 内置 image_gen 通道当前返回 404；已改用 `tools/agnes_gen.ps1` 产出概念图
- Tripo API 当前余额为 0；Hunyuan3D 免费 Space 可出白模，但受每日 GPU 配额限制
- Hunyuan3D 2.1 为非商用许可，当前三职业白模只能用于原型验证
- 免费白模没有骨骼、动画和贴图，脸部细节与武器拓扑仍需手工重做
- 升级 NPC 已换 3D 模型；头顶发簇有破面未修，暂无骨骼动作，52 骨略超 50 骨预算
- 最终 NPC 高模雕刻和 2K 烘焙在当前 8GB 内存/无独显机器上会很慢，建议本地低中模 + 云端或外接工作站做高模烘焙
- Blender 的四个 AI 建模服务均未配置 key，暂时只能用本地建模
- 战士的剑目前是背后挂载的占位摆法，待调整
- 地面目前只有 Albedo + Roughness，法线、AO 和贴花层后续补
- 黄沙岗怪物显示名已改，但模型和动画仍用占位体
- 自定义男角色模型已入库，但尚未加完整选人界面和骨骼重定向
- Blender 优化后的 GLB 在 Hyper3D MCP 上传时出现 `FILE_VALIDATION_FAILED`，鬼兵/风灵等需改从 Hyper3D 原始 GLB 直接绑定后再减面
