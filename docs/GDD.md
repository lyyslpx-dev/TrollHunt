# 游戏设计文档

状态：Q 版传奇方向，垂直切片范围已定。

## 定位
2.5D 斜 45 度 Q 版传奇手游，单机离线，横屏，触屏操作。
对标 Q 版传奇广告素材的观感，实机做八成还原。

## 核心循环
进图 → 自动/手动刷怪 → 爆装 → 捡取对比 → 穿戴强化 → 打 BOSS → 转生 → 下一张图

## 视角与操作
- 正交相机，俯角 45°、偏航 45°
- 左下虚拟摇杆移动，右下四个技能键
- 普攻自动索敌，技能手动释放
- 自动战斗开关：自动寻怪、自动放技能、自动拾取
- 支持蓝牙手柄

## 职业（垂直切片先做战士）
三名可玩职业全部为男性；每个职业各有一套 1–60 级的五档等级外观。

| 职业 | 定位 | 主属性 |
|---|---|---|
| 战士 | 近战爆发、高血 | 攻击 / 生命 |
| 法师 | 远程 AOE、脆皮 | 魔法 |
| 道士 | 召唤与持续伤害 | 道术 |

## 战斗
- 普攻三段，自动面向最近目标
- 四个技能，冷却 3–12 秒，其中一个带位移或控制
- 伤害公式：`(攻击 × 技能倍率 - 防御 × 0.5) × 暴击 × 随机(0.9–1.1)`
- 附加属性四类：暴击率、暴击伤害、吸血、切割
- 受击表现：闪白、击退、飘字、震屏
- 死亡：3 秒原地复活，掉 10% 金币

## 装备
- 八个部位：武器、衣服、头盔、项链、手镯、戒指、腰带、鞋子
- 五个等级阶：T1 1–9、T2 10–19、T3 20–29、T4 30–49、T5 50–60；10/20/30/50 级整点解锁下一阶
- 阶决定外观和基础数值区间，品质决定属性系数、附加属性条数和光柱颜色
- 品质：白 < 绿 < 蓝 < 紫 < 橙 < 红 < 神话
- 品质影响基础属性系数、附加属性条数、地面光柱颜色

### 装备掉落

装备阶由地图决定，等级只决定能不能穿。品质权重按地图难度递增，完整权重在 `data/drop_tables.json`。

| 地图 | 装备阶 | 小怪掉率 | 精英掉率 | BOSS 掉落 |
|---|---:|---:|---:|---|
| 黄沙岗 | T1 | 10% | 40% | 无 |
| 沙地遗迹 | T2 | 9% | 38% | 3 件 |
| 幽影森林 | T3 | 8% | 36% | 3 件 |
| 寒霜堡垒 | T4 | 8% | 35% | 3 件 |
| 熔岩深渊 | T4 | 7% | 34% | 3 件 |
| 黄泉鬼域 | T4 | 7% | 33% | 3 件 |
| 天空浮岛 | T5 | 6% | 32% | 3 件 |
| 海底龙宫 | T5 | 6% | 31% | 3 件 |
| 魔域·血月 | T5 | 6% | 30% | 3 件 |
| 擂台 | 无装备 | 0% | 0% | 0 件 |

BOSS 第一件保底紫，其余从蓝到神话按地图权重抽取。
跨阶地图允许提前掉落下一阶装备；等级不足时可以拾取和存仓，但不能穿戴。

未穿戴装备时显示基础身体与默认短裤；装备靠打怪获得，不自动发放整套外观。

### 安全区 NPC

黄沙岗安全区放置装备升级 NPC「胖哥」：

- 靠近后显示「装备升级」按钮，点击打开升级面板。
- 非交互状态随机播放敲装备、擦汗、伸懒腰、待机呼吸。
- 安全区内敌人不得进入或攻击玩家，离开安全区后恢复战斗。
- 当前使用 2D 立绘占位，后续替换为正式 3D 模型。

## 强化
- 武器和衣服可强化 +1 到 +15
- 成功率随等级下降，失败不掉级
- 强化石由小怪、精英和 BOSS 掉落

## 掉落
- 小怪：金币、药水、白装和绿装
- 精英：蓝装、紫装、强化石
- BOSS：橙装或红装保底，神话 3%
- 地面掉落显示品质光柱

## 怪物与地图
- 共 10 张图，完整配置见 `docs/MAPS.md`
- 1 张新手刷级图（黄沙岗）、8 张主线图、1 张擂台
- 难度随主线递增，擂台 20 级独立解锁
- 垂直切片先做黄沙岗 + 沙地遗迹

## 成长
- 等级 1–60，经验曲线前快后慢
- 60 级可转生，重置等级换属性点
- 垂直切片先做到 30 级
